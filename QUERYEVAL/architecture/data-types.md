- Tuple
- Sets 
- List/Array
- etc.

Logical operators perform actions on logical types:
- Selection
- Insertion
- Deletion 
- etc.

## Physical Data Types

Physical representation:
- Files
- Records 
- Byte Arrays

They have own manipulation rules defined by physical operators
